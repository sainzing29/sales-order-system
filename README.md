# Sales Order System

Full stack application using:

- Angular 21 Standalone
- .NET Core Web API
- SQL Server
- JWT Authentication

## Features

- Secure Login
- JWT Authentication
- Role-based Authorization
- User List
- Sales Order CRUD
- Dynamic FormArray Items
- Multiple row add/remove/update

---

## Setup

### Database

Run:

database/DB.sql

---

### Backend

Open backend solution.

Update connection string.

Run:

dotnet run

---

### Frontend

cd frontend/sales-order-ui

npm install

ng serve
